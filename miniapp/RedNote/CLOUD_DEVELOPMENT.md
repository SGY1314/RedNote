# 云端交接连接

发布助手只连接配置的真实交接服务。收到工作台二维码参数后才发起请求；未配置时提示不可用，不提供离线示例或 JSON 导入。

## 配置

从仓库根目录同步开发副本并连接现有 HTTPS 服务：

```powershell
.\scripts\sync-miniapp.ps1 -Destination 'C:\path\to\your\RedNote'
```

同步脚本保留 AppID 与本地运行设置。首次配置时，在开发副本 `config/runtime.local.js` 写入公开连接项（用自己的交接域名替换示例）：

```js
module.exports = {
  gateway: 'development-cloud',
  apiBaseUrl: 'https://your-handoff.example.com',
  developmentEditorCheck: true
};
```

不要在小程序中保存服务端密钥。清空本地配置为 `module.exports = {};` 并重新编译，会恢复“未连接”状态。

## 手机验证

1. 在开发者工具重新编译、预览，确认当前小程序代码和可访问版本。
2. 在工作台选择已确认的图文稿件，点击“生成二维码”。
3. 用小红书扫一扫扫描工作台二维码，自动载入稿件并复制标题、正文和话题；核对全部图片及文案。
4. 图片与接收授权检查完成后，点击底部“发小红书”直接打开官方编辑器，无小程序内二次确认。
5. 若官方发布页只带入图片，可长按粘贴已复制的完整文案，再整理标题和正文，自行确认发布。

手机和素材均使用同一配置来源的 HTTPS 地址；手机的 `127.0.0.1` 不是电脑。回环 HTTP 仅供识别为开发工具的模拟器使用。更换服务后必须重新编译小程序，并在工作台创建新交接。

## 会话与排查

接收凭证按服务地址和取件码隔离，最多保存 4 份、最长 10 分钟且不超过服务端有效期。只保存短期凭证，不保存稿件内容或账号凭据；同机重开会重新向服务读取。取消、撤销、失效和到期后不能继续访问。

若提示二维码已被使用，请在原接收端继续；原端凭证已丢失时，在工作台撤销并重新创建。若连接失败，检查服务 `/health` 和手机预览的连接配置；本地工作台通过现有私有通道上传时，可运行 `scripts/start-remote-relay.ps1` 恢复该连接。

平台暂停服务或未上线版本的二维码入口问题，需要分别处理；改动此连接配置不能解除平台限制。详见[网站稿件核对](../../docs/website-draft-check.md)。
