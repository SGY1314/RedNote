# v24 示例图界面落地与场景验收

接续 v22/v23，已恢复旧版 #xhs/… 和 #douyin/… 书签兼容，设置/任务支持独立路由。按原有 26 个示例场景核对真实组件。截图使用测试数据，展示真实前端渲染，不是静态设计图。

## 本版补齐

- 工作区设置改为独立页面，账号、工作区说明、统一模型配置说明和计费入口直接可见。
- 用户后台任务改为独立页面，提供项目/任务/阶段搜索，全部、进行中、已完成、待处理分组，以及安全重试、删除历史和清空历史。返回时打开原工作页面与所选项目。
- 后台任务管理增加用户/任务/项目搜索与已完成筛选。
- 管理总览增加四个快捷入口与真实最近任务，保留原有用量、费用及待办状态。
- 手机发布面板增加准备内容、手机打开、手机核对三步，状态来自真实交接状态；保留撤销、重新生成、短期凭证保护和前后台轮询规则。
- 保留 v23 的笔记详情完整页面、仿写列表与编辑区分离、完整发布预览、真实来源版本及手机媒体不裁切修正。

## 验证范围

- all-scenes-ui.cjs 覆盖 01–26 全部场景，在 1440/390/320 像素下生成 78 张实际界面截图并检查横向溢出。
- utility-pages-ui.cjs 验证任务搜索、分组、设置/计费跳转以及返回原项目。
- mobile-publish.cjs 验证扫码、撤销/重建、防重复、凭证恢复限制和前后台轮询；media-history-ui.cjs 验证历史删除不删除产物且保留进行中任务。
- 其余回归包含 full-page-details-ui.cjs、experience-ui.cjs、model-delete-ui.cjs、项目导航、发布素材选择及仿写保存逻辑。

## 与静态示例的差异

真实内容、模型数量、任务状态、权限和错误信息均以服务端为准。手机发布和提示词编辑保留对话框，以保留短期票据、返回上下文和已有保存保护；发布结果仍由用户完成实际发布后记录。未伪造采集服务健康、已配置模型数量或已发布状态。

## 发布

本次仅更新 web/dist，升级脚本先备份旧前端、校验文件，再原子替换 index。服务端程序、数据库、账号和小程序环境配置不变。源码包排除账号、密钥与本地连接配置。
