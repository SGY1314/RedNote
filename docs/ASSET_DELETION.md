# 素材删除与引用保护

删除仿写项目不等于删除采集笔记或独立发布稿。项目、笔记在回收站时也继续保留素材引用，以便恢复。

2026-10-11 修复：先删除采集笔记时，为仿写项目保留的原文快照，在仿写项目也被彻底删除后不再单独阻止素材清理。仍有采集笔记或仿写项目引用的原文快照继续保护媒体；发布稿、提取文本引用、运行中的媒体任务仍独立检查。

批量彻底删除仍保持全有或全无。受保护时显示每份受阻素材的占用来源，并可选择未被占用的部分；这个按钮只调整选择，需要用户再次点击删除并确认才会移除文件。

回归覆盖：笔记和仿写先后删除留下旧快照、回收站中的笔记及项目、图文/视频隐藏选择、封面、发布稿、提取文本、运行任务、整批不部分删除和本地文件后台清理。

本次修复不自动清理用户数据库或素材；需重启工作台加载新版后端，再在素材回收站执行删除。
