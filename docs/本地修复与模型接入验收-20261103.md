## 当前配置缺口

只读检查中央模型目录，仅统计记录数量及凭据是否存在；未输出、解密或使用密钥。

| 环节 | 模型记录 | 存有凭据的记录 | 下一步 |
| --- | ---: | ---: | --- |
| 标题仿写 | 0 | 0 | 添加独立模型配置和密钥 |
| 文案仿写 | 3 | 0 | 为所选文案模型配置密钥 |
| 图片仿写 | 1 | 1 | 核对模型、参考图协议及真实调用权限 |
| 视频仿写 | 1 | 1 | 核对模型、原视频输入能力及真实调用权限 |

通用/旧版模型目录的密钥不会自动替代标题或文案环节。保留各环节独立配置，未擅自复制凭据或覆盖现有目录。

文本实现使用 OpenAI 兼容的 Chat Completions 接口，并要求结构化 JSON 输出。服务地址应为 API 基础路径，例如服务商指定的 `/v1`，不是包含 `/chat/completions` 的完整生成地址。其他原生协议需要相应适配。

图片必须选择支持参考图的模型及对应协议；视频的原视频参考流程已覆盖 Ark/Wan 实现。单凭文本密钥不能证明图片、视频也有权限。后台“测试连接”只检查鉴权/模型目录，不能替代实际生成。

密钥准备好后，应在后台分别配置服务商、基础地址、准确模型 ID、输入能力和密钥，先对每个环节执行一次最小真实生成，再验证下载、保存与发布稿。届时才能确认真实供应商验收完成。
