# 界面优化 v21（2026-10-26）

- 采集库的卡片、列表、笔记详情共用个人评分与标签组件：支持已有标签、预设标签、自定义标签以及即时保存。
- 笔记详情移除“处理记录”页签；后台任务仍可从主界面右上角进入。
- 推荐角度保留在标题仿写内；每个项目仍只有一篇参考帖子。图片与视频保持独立步骤。
- 模型与创作方案默认折叠，可通过“调整设置”修改；缺少模型时展开配置。各环节分别记住选择。
- 候选标题显示字数与选用状态；小红书标题超过20字禁止确认。候选文案显示摘要，可展开全文与话题。
- 手机端步骤菜单默认折叠；参考内容按需展开；当前操作固定在底部导航上方。
- 标题/文案的底部操作随是否已选内容切换为生成或确认。图片按规划、确认、生成顺序切换操作。视频按生成脚本、确认脚本、生成视频切换操作。
- 统一“添加素材”入口，可选择素材库或本地上传。图片参考、结果与发布素材采用紧凑预览，支持查看完整图片。
- 发布稿历史按版本单独展开；修改已确认内容时提示检查后续内容。草稿与历史结果继续保留。
- 管理员提示词编辑在手机端采用接近全屏的面板。

## 验证

`npm run build` 检查 TypeScript 并生成网页资源。
`node web/tests/experience-ui.cjs` 在模拟接口下验证真实页面交互，覆盖360–1440像素、标签跨视图保存、无处理记录、标题字数限制、创作方案请求、文案展开、素材选择、本地上传、视频脚本确认与底部操作切换。不会调用付费模型。
`node web/tests/rewrite-workflow.cjs` 等相关逻辑测试检查草稿保存、版本、模型目录及发布素材顺序。

已有的 `unified-platform.cjs` 仍按旧版 `readRoute` 函数提取处理器，与 v20 已采用的 `parseRoute` 不一致，不能作为本次界面修改的通过项。应用路由文件未在本次修改。

本次升级包只替换 web/dist，服务端程序、数据库和小程序配置不在包内。先备份原 web/dist，复制带哈希文件名的资源，最后替换 index.html；回退时恢复原 index.html 与备份资源。
