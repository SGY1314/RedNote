# AI 视频导演（2026-10-11）

## 使用

仍使用统一仿写库。在编辑器「当前版本素材」切换到「视频」，打开「AI 视频导演」，按以下顺序操作：

视频与图文共用左侧参考、右侧创作编辑的布局，以及目标读者、语气、篇幅、标题、正文、话题、版本保存和比较操作。视频创作编辑处可直接选择「本次文案模型」与「本次视频模型」；视频模型选择与导演面板双向同步。左侧可勾选来源图片和视频，导演自动带入这些选择，移除参考也同步返回编辑页。图文与视频分别保留参考选择，不混用成品素材。导演脚本模型默认沿用本次文案模型，有画面参考时优先选择支持图片理解的模型，并可单独调整。

1. 写好文案，选择自己的图片、参考视频或上传本地素材，填写补充要求。选择目标视频模型，直接输入希望生成的总秒数（整数）；页面显示该模型的单次时长范围。
2. 选择脚本模型，点击「生成完整脚本」。只调用文字／视觉规划接口，不自动生成视频。
   模板里的时间线数量、时长和口播长度按本次输入动态生成（例如 6 秒连续视频为 1 条 6 秒时间线、口播最多 24 字）。模型返回内容但格式不合格时，最多额外调用一次文案模型修正，因此可能多一次文案调用费用。网络、权限、输出截断及参考图无法理解不走自动格式修正；两次仍不合格会显示具体缺失字段、数量或时长问题，不保存伪造脚本，也不提交视频任务。
3. 查看完整故事、主体与风格、从 0 秒到目标时长的画面时间线、运镜和完整口播。可修改并保存为新脚本版本；确认完整脚本后才能制作。修改总时长后要重新规划脚本。
4. 点击「根据确认脚本生成完整视频」。一次提交整条视频，按时间线推进开场、发展和结尾，不固定拆成三个独立任务。结果保存到本地，预览后点击「预览满意，制作成片」。
5. 成片可选入当前版本素材，随后点击编辑器的「保存完整版本」，将文案与成片一起保存、比较、确认及建立发布稿。小红书扫码发布使用平台默认封面，生成封面单独保留供下载；抖音继续选入成片与封面。

列表顶部有独立「视频模型配置」：默认基础地址 `https://ark.cn-beijing.volces.com/api/v3`，默认模型 `doubao-seedance-2-5-260628`。另支持阿里云万相 `wan3.0-video-prime` 与 `wan3.0-video`，地址填写 `https://业务空间ID.地域.maas.aliyuncs.com/api/v1`。识别到万相官方业务空间地址时自动使用其异步视频协议，兼容此前误填的 `/compatible-mode/v1` 地址和模型大小写，并保持原业务空间、地域及密钥。需要有效密钥与对应权限；不把任意 Chat Completions 或 Images Generations 模型当作视频模型。连接检测只读取模型列表，不提交视频任务，也不证明真实生成权限。

脚本模型使用现有「文案模型配置」：需要 Chat Completions、JSON 输出；有图片或视频参考时还需支持 Base64 `image_url`。配置和密钥保存在后端，每次任务冻结所用服务配置，修改配置不会改变已有任务。

## 参考与制作范围

- 原始文案采用编辑器当前内容，包含未保存修改，并随脚本保存快照。参考素材由用户明确选择，最多 7 份，其中视频最多 2 个，每个不超过 10 分钟。
- 图片读取实际图像。视频按 0%、25%、50%、75% 位置抽取 4 帧，并附带该视频已有的 ASR 文本（包含人工修正）。这不是完整连续视频理解；没有已有转写时不分析声音，不自动进行语音转写。
- 新脚本使用 `brief.mode=continuous`，内部 `shots` 只有一个元素，其时长等于输入总时长。画面描述含连续的起止秒数，规划要求事件承接、不重复开场或复述同一件事；整个时间线一次提交视频服务。台词限制为每秒最多 4 字，仅为长度检查，不等同于实际配音时长测量。
- 已核实时长：万相 3.0 为 2～30 秒，Seedance 2.5 为 4～30 秒，Seedance 2.0 为 4～15 秒，Seedance 1.5 pro 为 4～12 秒，Seedance 1.0 pro / pro fast 为 2～12 秒。均为文生视频整数秒；未知模型别名不猜测其能力。超过范围会在付费任务入队前拒绝，不自动拆段或截断。暂不提供超过单次上限的视频延长。
- 历史脚本未设置 `mode`，仍保留 15 秒 3×5、30 秒 3×10、60 秒 6×10 的读取、编辑、重试及合成能力，界面提示重新规划可切换连续视频；不会自动迁移旧任务、覆盖旧成片。
- 视频生成使用确认脚本中的文字描述；本版不直接向视频生成服务上传参考视频或图片。风格与主体靠脚本描述约束，一致性需预览真实结果。
- 输出请求为 9:16、720p。可请求模型生成同步声音和中文台词；本版使用视频模型原生音轨，不含独立 TTS、逐句字幕、SRT、背景音乐配置或字幕烧录，台词与声音不保证严格复现。不是原始规划中独立配音与字幕方案的完整实现。
- 合成使用已有 FFmpeg，由单并发本地任务执行，不新增 Node / HyperFrames 服务。统一为 720×1280、H.264、AAC、30fps，较宽画面按比例补边，输出 MP4 和首帧 JPEG 封面。保留模型音轨；无音轨时补静音。检查每镜实际时长，偏离脚本超过 1 秒则阻止合成，避免掩盖异常结果。
- 连续视频支持使用同一确认脚本重新制作，显式确认费用并保留旧结果。历史分镜继续支持整组生成及单镜重做并复用其他完成镜头。处理中的远程任务或待下载结果须先继续查询，提交结果不明须先核实关联；暂未提供替换片段及字幕编辑器。

## 版本与恢复

- 数据迁移 `005_video_director.sql` 新增 `video_scripts`。每次脚本修改创建新记录，确认只作用于该记录；旧脚本、镜头、成片和已保存的文案素材版本保留。
- 任务仍在 SQLite 队列中执行，脚本、视频生成、本地合成各单并发，关闭页面不停止任务。
- 视频提交前持久化 `submitting`；取得远程 ID 后立即保存，再轮询。已有远程 ID 的运行中任务重启后继续查询，不重新创建。下载失败也查询同一 ID。
- 提交断线、5xx、无有效任务 ID 等不确定情况保持暂停，普通重试接口拒绝再次 POST。用户在所选视频服务商核实后，可关联该镜头远程 ID，继续查询。明确的 400/401/403/404/422/429 拒绝可由用户手动重试，不会自动重投。
- 远程失败／取消／过期不会自动重做。其余完成镜头保留；用户可显式新建整组制作或重做指定镜头。旧版生成请求仍返回已有任务；新制作的请求编号防止重复提交，配置取自本次选定模型并冻结保存。
- 项目回收站保留脚本；彻底删除项目清理脚本、相关任务与加密模型快照。脚本参考、镜头和成片文件仍受引用保护；项目彻底删除后可在素材库清理，没有删除其他发布稿快照。
- 远程下载按提供商限制为 HTTPS 火山媒体域名或阿里云 OSS 结果域名，逐次校验重定向及 DNS 公网地址，限制 512 MB，落盘前用 FFprobe 检查真实媒体。
