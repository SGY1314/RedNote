# AI 图片生成与排序（2026-10-10）

- 配置入口（2026-10-11 调整）：仿写库列表 → 图片模型配置；同一工具栏提供文案模型配置。打开项目后，在“创作编辑”分别选择“本次文案模型”和“本次图片模型”。“我的发布素材 → AI 生成图片”沿用已选图片模型。
- 独立图片模型配置；密钥加密、掩码查询、每个任务冻结服务配置。
- 同步 Images Generations 协议，支持单张或 2–6 张连续画面，每次向模型请求一张并逐张落盘；可选尺寸，默认省略尺寸参数。支持 Base64 与允许域名的公网 HTTPS 图片链接，不提供视频生成。
- 图片验证后写入本地素材目录，预览后可加入图文素材。排序复用持久化媒体选择接口，图片与视频选择相互独立；已有发布稿快照不受后续排序影响。
- 单并发生图，禁止同项目重复排队。服务重启不自动重投运行中的付费任务。任务已有本地结果时重复执行复用结果，不重新调用模型。下载失败后的人工重试可能重新调用模型并计费。
- 图片生成中阻止删除项目。彻底删除项目会删除任务和加密配置快照，图片素材保留；素材仍可通过素材库单独删除。

## 参考图片与当前文案（2026-10-11）

- 编辑器左侧“参考内容”展示该项目来源快照中的图片。手动勾选用于 AI 配图的图片，图号按勾选顺序排列；原笔记重新采集不会替换旧项目的参考图片。
- “AI 生成图片”抽屉显示本次所选图片，可以移除；默认勾选“参考当前文案”，传入右侧实时标题、正文、话题，包括尚未保存的修改。可关闭文案引用，或补充画面要求。只有文案或只有参考图也可以提交。
- 参考图直接读取本地真实图片字节，以 Base64 data URI 发给图片模型，不依赖 OCR，也不会触发 OCR。
- 自动识别百炼官方域名的 `qwen-image-3.0` / `qwen-image-3.0-pro`（最多 3 张）和 `qwen-image-2.1-pro` / `qwen-image-2.1-turbo`（最多 10 张）。这些官方模型 ID 自动规范为小写。
- 其他模型默认仅文生图。只有供应商明确兼容 `/images/generations` 顶层 `image` 字符串数组及 Base64 输入时，才在“图片模型配置 → 参考图支持”中选择扩展协议（默认最多 3 张）。不支持 OpenAI `/images/edits` multipart 协议；不支持参考图的模型不会悄悄忽略所选图片继续调用。
- 输入支持 JPEG、PNG、WebP、GIF，单张不超过 10 MB、边长不超过 8000、长宽比不超过 10:1。提交前检查可用性并保存 SHA-256；执行前再次核验，文件改变则阻止调用。排队和运行中的任务保护参考文件，不能彻底删除。
- 任务保留提交时的文案、画面要求、参考图顺序和校验值、模型配置；后续编辑不会改变本次任务。生成结果继续作为新素材保存，不覆盖来源图片。
- 协议依据：[百炼 Qwen 图像生成与编辑 API](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)，采用 OpenAI 兼容模式的 `image` 扩展字段。
