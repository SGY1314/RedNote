## 接口补充

- `POST /rewrites/:id/refresh-sources` 返回更新后的项目。原笔记版本保持固定，仅显式刷新其素材的提取文字。
- `POST /rewrites/:id/video/generate` 兼容旧请求。新制作传 `previous_job_id`、`request_id`；只重做一个镜头时再传从 0 开始的 `redo_shot`。不传 `redo_shot` 则重新生成整组。
- `GET /sync?cursor=0&epoch=` 返回 `changes`、`cursor`、`epoch`、`reset`、`more`。`value=null` 表示删除。`reset=true` 时先清空旧缓存再应用当页；`more=true` 时继续读取。同步内容仅包含任务、素材、项目、发布稿。
- 迁移 `006_incremental_sync.sql` 建立持久化变化记录；每条记录只保留最新变化，事务回滚不会发出错误更新。

## 2026-10-13：文案钩子与写作规则

### 图片仿写可选素材库参考

- 图片生成接入素材库选择器，仅显示可用图片，支持名称/分类搜索、预览、多选和移除。所选 ID 从全部素材解析，保留来源图片兼容，按选取顺序同时传入画面规划与图片生成。
- 选择器复用视频导演入口，图片模式按模型及连续画面预留位限制数量；视频模式保持 7 份总量、最多 2 份视频。提交时再次过滤失效素材、去重和检查数量，超限选择允许逐项移除。
- 只改变参考素材选择，不复制素材文件、不改变发布素材或已保存版本。

### 默认文案更自然

- 以使用者为发帖作者、帖子受众为读者，直接生成成稿；在所有文案钩子下默认加入自然表达要求，保留用户语气、观点和用词，减少模板化结构、流行套话和强行互动。
- 明确区分作者资料与来源博主经历，不编造个人体验、生活细节或情绪，不靠错字和语病模拟真人。输出前在同一次调用内检查冗余和套话，不增加模型调用。
- 规则随新任务冻结并保存在版本要求中，已保存文稿不变。模拟接口回归检查规则实际进入模型请求、语气和篇幅仍在、单次调用及历史版本保持不变；模拟测试不评价真实模型的文案质量。

### 发帖角度与图像、视频钩子联动

- 文案编辑新增共享角度及异步角度建议（3 个备选，手动选用）；接口沿用模型配置快照，任务恢复不会自动重发结果不明的调用。
- 图片与视频可继承或覆盖共享角度，分别选择首图和开头策略、自定义要求。后端验证枚举和长度，图片规划、图片生成、视频规划都使用冻结的提交参数。
- 文案/角度/钩子变化提示重新规划；异步图片规划的指纹加入对应角度、钩子，避免等待期间的新修改被覆盖。
- 完整版本保存角度设置，素材来源按选中的资产追溯并冻结公开生成输入和脚本，明确区分版本编辑设置与素材原始生成记录。模型密钥及服务商原始响应不进入版本。
- 覆盖角度建议不创建文案版本、三类提示词传递、继承/覆盖、非法参数、历史不可变性、素材记录去重与敏感字段排除、前端过期提示和生成期间修改保护。验证使用模拟模型与组件渲染，不代表真实模型效果或真实发布成功。

文案编辑新增七种开头策略，默认自动选择。后端校验策略，按目标读者、语气、篇幅和补充要求，将钩子及自然表达、事实约束、标题正文一致等规则传给文案模型。任务与生成版本保存策略和要求快照；人工另存版本保留父版本的钩子记录，旧版不补填。版本选择和完整对比展示钩子来源。沿用一次文案请求，无额外规划调用。
