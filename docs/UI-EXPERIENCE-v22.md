# v22：按已确认示例图调整工作台

本版调整网页界面，不修改服务端接口、数据库、小程序发布入口或模型调用协议。

- 用户登录采用深色品牌区与简洁表单；管理登录采用居中表单。
- 用户端与管理端统一米白背景、白色卡片、深灰导航和陶土色主按钮。
- 手机采集入口直接可见；搜索、标签、排序和视图切换继续放在列表外。
- 采集库、管理后台和用量表格在手机上转为带字段名称的记录卡片，复用原有数据、操作与分页。
- 发帖角度仍在标题仿写中；原始标题、原始正文和当前推荐角度直接显示。
- 模型、创作方案、补充要求、图片与视频提示词、尺寸、时长等创作设置直接显示，历史记录仍可展开。
- 图片参考恢复完整大图轮播，生成结果保留紧凑缩略图；图片和视频仍独立。
- 模型管理按九个环节切换，当前环节的模型详情直接显示；新增、保存、检测连接、清除密钥和删除保留。
- 保留标题二十字限制、标题与文案的确认顺序、自动保存、版本、素材选择、本地上传与服务端权限。
- 抖音发布仍保留待接入状态，不将前端占位显示为已完成发布。

## 验证

`npm run build` 编译生产网页。

`node tests/experience-ui.cjs` 验证展开设置、参考图轮播、20 字限制、自动保存请求、标题/文案确认、素材库选择、本地上传和视频脚本确认；覆盖 360–1440 像素宽度。

`node tests/approved-pages-ui.cjs` 用隔离的模拟接口检查用户端、登录页和全部管理页面在 1440、390、320 像素宽度的布局，生成真实组件截图并检查页面溢出和浏览器错误。

`node tests/model-delete-ui.cjs` 验证模型分组切换、ASR 配置、输入能力、取消删除、分组隔离和删除失败处理。

测试中的示例内容只存在于测试接口，不写入真实工作区，也不调用收费生成接口。

## 升级与回滚

升级包仅包含 `web/dist` 和校验清单。部署前备份现有网页，资源文件先复制，入口文件最后原子替换。回滚时恢复部署备份中的 `dist/index.html`；旧哈希资源保留，因此已经打开的页面仍可读取原资源。
