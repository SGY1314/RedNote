# 抖音视频手机发布接入 · 2026-10-29

本次把网站的抖音视频发布稿接到现有 `douyin-publish` 云服务。小红书手机图文发布保持原入口。

## 当前阶段怎么使用

当前小程序只有开发者工具真机调试版本，因此先用开发调试模式。它不生成正式版二维码。

1. 在仿写项目保存并确认完整版本，建立目标平台为抖音的视频发布稿。
2. 在「发布管理」找到稿件，点击「手机扫码发布」→「创建调试任务」。
3. 网站将这份确认版本的标题、正文、标签和一个视频上传到抖音云，显示本次启动参数。参数是短期领取凭证，不要发给他人。
4. 打开已导入的抖音小程序项目，在自定义编译模式中设置启动页面 `pages/publish/index`，启动参数粘贴网站显示的整段内容，进入场景选择「扫一扫」（011007）。
5. 点击开发者工具「预览」，用已获得测试权限的手机抖音扫码。`manualClaim=1` 用于避免模拟器自动领取任务；手机打开后点击「重新领取」。
6. 手机下载并预览视频，核对文案，点击「前往抖音发布」。在抖音原生编辑器核对账号、封面、文案并自行决定是否发布。
7. 返回网站查看交接状态。手机成功回调仍待核实；确认作品后再手动记录已发布。

任务有效期15分钟，从任务创建时开始计算。已过期时在网站重新创建，并更新开发者工具中的启动参数和预览码。旧参数不能用于新任务。

关闭或刷新网站弹窗后不恢复领取凭证。若还未领取，请先撤销当前任务，再创建新任务。重复点击不会重复上传。

## 管理员配置

复制工作台根目录的 `config.douyin.example.json` 为 `config.douyin.local.json`，填写：

- `server_url`：已有抖音云服务的 HTTPS 源站地址。
- `control_key_file`：存放云服务 CONTROL_KEY 的文本文件绝对路径。内容须与运行中的云服务一致。
- `app_id`：小程序原始 AppID，不添加版本后缀。
- `app_secret_file`：存放小程序 AppSecret 的文本文件绝对路径，不能填对象存储 SK。
- `storage_host`：本应用对象存储桶的完整 HTTPS 主机名，不带协议和路径。
- `launch_environment`：当前设为 `development`。小程序线上版本就绪后才切换为 `production`。

两份密钥文件只保留在网站服务器中，不能放入 `web/dist`、小程序源码、Git 仓库或交付压缩包。升级包不包含密钥，也不会覆盖本机连接配置。

工作台服务启动目录默认是配置目录；若服务在其他目录启动，可在既有 `config/cloud.json` 中指定 `mobile_publish_config_dir` 为该配置目录的绝对路径。

## 正式二维码阶段

`production` 模式调用抖音官方二维码接口。开发者工具预览码与官方线上码是不同入口；当前调试成功不代表线上二维码已经验收。小程序上传、审核及线上发布仍须通过平台流程完成。正式切换后需要重新测试扫码、领取、下载和打开原生编辑器。

生成二维码失败会显示平台错误码；不会伪造预览码，也不会把任务标成已发布。

## 范围与限制

- 当前新增入口支持一个已就绪 MP4 视频，最多200MiB，标题最多60个字符；封面请在抖音编辑器选择。图文不走此视频入口。
- 后端核对稿件与确认版本一致，检查文件及可用的 SHA-256。上传地址必须属于配置的对象存储主机；控制密钥不会发送给存储服务器。
- 任务接口受既有登录、CSRF及用户独立数据库限制，抖音任务与小红书任务分开。
- 手机领取、下载、发起编辑、取消或成功回调均不自动改写网站的「已发布」。
- 抖音云现阶段使用本地 SQLite 临时保存任务。容器重建可能丢失未完成任务；这时需要创建新任务。正式多人使用前仍需处理持久化和多实例问题。
- 本轮没有修改抖音云镜像，也不会自动提交任何作品。
