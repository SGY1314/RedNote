# RedNote 内容创作工作台

用于参考笔记采集、标题与文案仿写、图片与视频创作、素材管理及双平台发布准备。

这是开发源码仓库，需要安装依赖并构建。已有项目、用户媒体、账号会话、密钥、数据库和运行工具链不在仓库中。

## 安装与启动

Windows 10/11 64 位，先安装 Node.js 22.12 或更新兼容版本，在项目根目录执行：

```powershell
.\setup.cmd
.\start.cmd
```

`setup.cmd` 联网下载项目独立工具链并构建前后端与本地发布组件。默认网址为 `http://127.0.0.1:8080`；`stop.cmd` 停止本目录的服务，`restart.cmd` 重启。首次安装使用配置示例，需要自行配置模型密钥和相关服务。

手动开发、验证命令及源码打包见[开发维护说明](docs/MAINTENANCE.md)。多用户与管理员配置见[多用户说明](多用户说明.md)。

## 主要功能

- **采集工作台**：解析小红书与抖音参考内容，保存可获取的文字和媒体，并提供图片文字提取、视频转写入口。
- **仿写工作台**：标题、文案、图片、视频分别配置和生成，支持手动编辑、素材选用、草稿保存与确认。
- **素材库**：管理上传及生成素材、重命名、分类和项目引用。
- **发布管理**：同一稿件可准备小红书和抖音发布，分别记录平台状态；下载、上传准备和打开官方编辑器均不等于已经发布。
- **管理端**：用户、模型、提示词、服务配置及用量管理，权限由服务端校验。

真实采集、模型生成和平台发布取决于供应商、账号权限、网络与配套服务配置。测试使用模拟接口时，不代表真实平台调用已验收。

## 源码目录

| 目录 | 内容 |
| --- | --- |
| `web` | React/TypeScript 前端、运行资源和测试 |
| `cmd`、`internal` | Go 服务、接口、任务、数据存储与测试 |
| `collector` | Python 采集器及固定版本第三方源码 |
| `douyin` | 抖音适配器与测试 |
| `publisher` | 小红书本地发布组件与测试 |
| `miniapp/RedNote` | 配套小红书小程序 |
| `scripts` | 环境安装、启动、停止、同步和打包 |
| `docs` | 当前功能说明、维护说明及最新检查报告 |

采集及发布组件的来源、许可证和裁剪范围见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
