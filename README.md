# Gin 小红书内容工作台

**新增手机发布**：发布管理提供「手机扫码发布」，手机接收图文后自动复制标题、正文和标签，再打开小红书官方编辑器由本人核对、发布。原有小红书桌面上传及本地版抖音发布代码保留；当前云端版仍禁用扫码登录、抖音采集和自动上传。手机功能需要另行配置公网 HTTPS 交接服务及小程序体验版，不能仅替换网站文件就启用。连接步骤见 [手机发布说明](docs/MOBILE_PUBLISH.md)。

本机单用户内容工作台：采集参考笔记、OCR／原视频转写、AI 仿写、多版本确认、选择自己的图片或现成视频、准备发布稿与扫码发布。

视频模式新增 AI 视频导演：根据文案、参考图片与视频采样帧生成完整脚本，确认后调用视频模型生成镜头，并使用 FFmpeg 本地合成。发布管理支持扫码连接自己的小红书账号，通过本机浏览器上传素材、填写文案，再由本人在官方页面预览并手动点击发布。

## 启动

当前工作区已经安装项目独立运行工具并完成构建。双击 `start.cmd`，打开 **http://127.0.0.1:8080**。关闭页面不会停止服务；双击 `stop.cmd` 停止本项目进程。

从源码包首次安装：先安装 Node.js 22 或更新版本，再双击 `setup.cmd`。脚本在 `.tools` 下下载 Go、Python 3.12、uv、FFmpeg，安装锁定依赖，运行 Go 测试并构建前后端。需要联网，不修改全局 Go/Python 安装。

也可以在 PowerShell 执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1
```

默认端口 8080、5556、18060。扫码发布需要本机已安装 Chrome 或 Edge。重复启动会提示已有服务，停止脚本核对进程路径和创建时间，不会按端口杀死无关进程。

## 抖音采集与发布（新增）

重启后，采集库支持识别抖音完整视频链接、短链接和分享文字，可按平台筛选。首版采集公开视频及封面、文案、作者和可获取互动数据；图片笔记不在抖音采集范围内。遇到登录限制，请到发布管理连接自己的抖音账号。

仿写库建立发布稿时选择“只发小红书”“只发抖音”或“两个平台都发”。双平台会一次建立两条关联发布记录，共用确认版本的文案和素材引用，不重复保存文件；目标平台固定在各自快照上。此前发布稿自动迁移为小红书。

发布管理 → 抖音账号 → 抖音扫码登录。在手机上确认后，工作台核实创作者中心账号，显示「可准备上传」，不再要求额外登录抖音主站。有效会话会加密保存；重启后可点击「检查账号」恢复检查，失效时重新扫码。选择“上传到抖音”，指定公开或仅自己可见，会打开专用官方浏览器并选择素材、填写文案。自动核对通过后可点击“核对并发布”；若编辑器回读无法自动核实，则保留官方编辑页并显示“待官网核对”，点击该稿件的“继续官方编辑”查看上传进度、文案和可见范围，在官网继续操作。待官网核对不代表上传完成或已经发布，也没有自动发布令牌。确认预览五分钟有效，服务重启、切换账号或打开专用浏览器都会使预览失效。结果不明只允许到创作平台核实，不能自动重新发送。

需要本机 Microsoft Edge。Playwright 1.56.1 由 setup.cmd 安装到独立 douyin 目录；不增加 HTTP 端口。支持自己的图片、MP4 与选定封面；账号权限和网页控件必须识别成功后才能继续。

**验收状态：代码与界面已接入，Go、适配器模拟测试和前端构建通过；真实账号扫码、登录后网页控件对齐、图文/视频上传及最终发布仍待本人联调。本轮开发环境的浏览器无法连接隔离的本机服务，因此未完成完整浏览器流程验收。** 请正常双击 Windows 启动脚本后操作；真实验收前不要把模拟通过视为实际发布成功。详见 douyin/README.md。

## 使用流程

**统一仿写库**：图片与视频仍在同一项目列表管理，在编辑器“当前版本素材”内切换“图文 / 视频”。图文模式显示参考图片、图片模型与 AI 生图；视频模式显示参考视频、视频文案／口播、上传视频及封面。切换保留各自已选素材和暂存内容，版本记录统一查看；视频模式提供「AI 视频导演」入口，先确认完整脚本，再生成镜头并预览合成。

**AI 视频导演**：在仿写库列表的「视频模型配置」填写火山方舟 API 地址、模型 ID 与密钥；在同一编辑器切换「视频」，打开「AI 视频导演」。脚本模型沿用文案配置，参考图片与视频抽帧需图片理解能力。完整流程、恢复规则及验收限制见 [视频导演说明](docs/VIDEO_DIRECTOR.md)。

**AI 图片与排序**：在仿写库列表点击“图片模型配置”，添加 API 基础地址、图片模型 ID 和密钥。打开项目后，在“创作编辑”选择“本次图片模型”，再点击“当前版本素材”区域的“AI 生成图片”。图片与文案配置独立，可保存多套图片模型。支持兼容 `POST /images/generations` 的同步图片接口，返回 `data[].b64_json` 或 `data[].url`（协议参考：[Images API](https://developers.openai.com/api/reference/resources/images)）。尺寸可留空使用供应商默认，也可填写模型支持的 `宽x高`。可选择生成 **1 张单图，或 2–6 张连续画面**，逐张编辑情节描述。图片实际保存至 `data/media`，本地素材库可按“AI 生成”筛选、重命名和分类。

**先规划画面，再生图**：选择张数后，点击“AI 自动填充每张画面”，根据当前文案和勾选参考图填好逐张描述；单张也支持。可手动修改每一张，再点击“生成图片”。画面规划使用独立选择的文案模型；有参考图时，需在“文案模型配置”中为真正支持图片理解的模型勾选“支持图片理解”。规划模型使用兼容 Chat Completions 的接口并支持 JSON 输出、`image_url` Base64 图片输入。图片生成模型仍单独选择。规划仅产生文字描述，不会自动调用生图接口。等待过程中有新修改时不覆盖，最近成功规划可展开查看并手动填入。规划和生图分别按供应商规则计费。

连续画面按顺序逐张生成，共享文案、统一外貌和风格要求、完整故事顺序。支持参考图时，后续画面使用首张成图辅助保持主体一致；参考位充足时还加入上一张成图衔接动作。可单张加入，或“按顺序加入整组图片”，再点击“保存完整版本”与文案一起保存。中途失败保留已完成图片，在后台任务手动重试时跳过已保存图片；每张实际调用可能计费。仅支持文生图的模型使用共同文字描述引导连续性，画面一致程度需根据真实结果判断。

左侧“参考内容”展示来源图片，勾选后可在“AI 生成图片”中与当前文案一起使用。默认带入右侧正在编辑的标题、正文和话题（包括未保存的修改），也可取消文案引用、补充画面要求。图片直接传给模型，不需要 OCR。百炼 Qwen Image 3.0 自动支持最多 3 张参考图，2.1 最多 10 张；其他服务需在图片模型配置中明确选择兼容的参考图协议，详见 [图片生成说明](docs/IMAGE_GENERATION.md)。

图片上的“前移 / 后移”按键会自动保存顺序，AI 图片与上传图片可以混排，切换视频后再回来仍保留。图片生成不会替换已有素材或改动已建立的发布稿；需要更新发布内容时重新建立快照。视频封面也可选用已生成的图片。调用可能计费，断线或服务重启不自动重复生图；结果不明时先核实服务商记录，再在“后台任务”手动重试。首版 URL 下载限已允许的媒体域名、供应商 API 同域和 Azure Blob 公网域名；其他返回域名请使用 Base64 响应。

文案模型在 **仿写库 → 文案模型配置** 中管理（与图片模型配置并列放在项目列表，编辑器只选择已配置的模型）。可新增多套配置，分别填写名称、API 基础地址、模型 ID 和密钥，支持兼容 Chat Completions 的文字接口；旧的文案配置显示为“原文案模型”。OCR 和转写仍在底部设置中管理。

打开项目后先填写“创作主题”并勾选参考帖子，再选择“本次文案模型”，填写读者、语气、篇幅和要求，点击“生成试写文案”。新结果进入“试写历史”，不占用完整版本号；可切换另一模型再次生成，历史结果不会覆盖。“版本比较”可分别选择左右两个已保存版本，查看模型、时间、生成要求、标题、正文和话题，再点击“选用并编辑”；试写内容需配好素材后保存为完整版本，完整版本才可确认选用。修改后保存新的完整版本，并保留来源记录 ID 与模型信息。未保存修改切换前会提示。

每个生成任务保存提交时的配置快照，后续改模型配置不会改变排队任务；密钥经 DPAPI 加密，只保存在后端，任务列表与版本不会返回密钥。未配置密钥时显示“待配置”，仍可手动编辑。真实生成会调用用户配置的服务并可能计费；连接检测通过不代表实际模型调用权限已验证。

**文案与图片是一个完整版本**：点击“保存完整版本”，一次保存标题、正文、话题、素材、封面和图片顺序；AI 文案版本保留提交任务时的素材选择。编辑器切换、版本比较、确认和发布均以整套内容为单位。对比左右两栏分别展示各版本的图片，点击可放大查看，视频版本还可预览视频与封面。修改文案、替换图片或调整顺序后需保存并确认新版本；旧版本保持不变。素材自动暂存只是编辑草稿，不会更新已保存或确认的版本。

发布稿只提交版本 ID 和目标平台，后端从确认版本读取文案与全部素材；任何另行传入且不一致的图片、顺序、封面或素材类型都会被拒绝，避免混用不同版本。已有发布稿保持原快照。升级前缺少素材记录的历史版本会提示“未记录配图”，需选好素材后保存为新的完整版本才能确认和发布。历史版本使用的文件不能彻底删除，彻底删除所属仿写项目后可在素材库继续清理。

1. **直接采集**：粘贴完整的小红书笔记链接或分享文字，点击“开始采集”。直接读取公开页面，无需配置登录信息；受登录限制的笔记会提示无法直接采集。AI 文案与图片模型在仿写库配置，OCR、转写在设置中配置，不影响笔记元数据采集。密钥留空保持原值，清除按钮需要再保存才能生效。
2. **采集参考**：粘贴链接或分享文字，支持批量（每次最多 50 条）。采集仅保存原文和媒体地址，不自动下载图片、视频或封面到素材库。打开笔记详情可在线预览，逐个点击「下载到素材库」，或勾选后点击「下载所选到素材库」。下载成功才在素材库显示；重复点击不会重复下载，失败可单独重试。在线预览不保存媒体文件，需网络且可能因平台地址过期失败，此时重新采集或打开原笔记。重复笔记定位已有记录；重新采集产生新来源修订。已下载素材和历史版本保留。新版启动会停止旧版未完成的自动下载任务；用户主动提交的下载仍可恢复。
3. **编辑内容**：加入仿写库，勾选原文、OCR 或转写来源，填写目标读者、语气、长度和要求。也可以空白新建并手动编辑。每次保存创建新版本；确认版本后，修改需保存为另一个版本。未保存的文案在当前浏览器暂存，正式版本以数据库为准。
4. **选择自己的素材**：图片可上传、选择、移除或上下调整顺序；视频稿选择一个现成视频，可以另选图片封面。文件复制到工作台媒体目录，原文件移动不影响工作台。采集媒体也可明确选用，默认不会自动加入发布稿。
5. **建立发布稿**：确认文案并选定素材后建立快照。图文稿缺省以第一张图片作为封面。未选素材可以保存“待准备”稿；需要回到项目选好素材并建立完整的新快照。
6. **小红书预发布**：扫码连接账号后，选择发布稿并点击“上传到小红书”。工作台自动上传素材和填写文案，保持专用官方编辑窗口打开；本人预览并点击官方“发布”。工作台显示“待手动发布”，需要本人确认成功后点击“记录已发布”确认时间（无需作品链接）。窗口已关闭时，核实未发布后重新准备。复制文案、下载素材和打开平台不会标记为已发布，发布包导出功能已移除。

登录状态在本机使用 Windows DPAPI 加密，无需填写 Cookie；登录失效后重新扫码。网页自动化并非官方开放接口，可能受到平台页面变化或验证限制。首次使用请用自己的账号进行小规模联调。图文封面会作为上传首图；视频暂使用平台默认封面，带自选视频封面的稿件会明确阻止在线提交，可下载素材后自行发布。成功后的作品链接可手动补充。详见 `publisher/README.md`。

ZIP 包含 `标题.txt`、`文案.txt`、按顺序命名的 `素材/01...`、所选封面和 `素材清单.json`。清单包含固定版本 ID、素材 ID、字节数和 SHA-256。

## 自己的帖子数据

发布管理 → 我的帖子数据 → 立即同步。先通过页面顶部扫码连接并检查自己的账号。读取过程为后台任务，页面每两秒刷新进度，耗时操作与发布共享浏览器操作锁。

首版读取本人主页当前加载的最多 20 篇作品，展示标题、作品链接、类型、可获取的发布时间、点赞、收藏、评论、分享及最近读取时间。当前读取来源不提供可靠阅读量，因此通常显示“—”；不能据此推断阅读量为零。详情读取失败时仍保存主页提供的字段，并标记“仅主页数据”。这不是全账号历史作品或创作中心完整经营数据。

每篇保留最近 30 次同步快照，可查看记录及相邻两次的变化。平台的“1.2万”等缩略数保留原样；只对精确整数字段显示增减，不把近似数当成精确统计。没有在本轮返回的历史作品标为“本次未读取”，不推断删除、违规或发布失败。该功能不会自动更改工作台的发布成功状态。

支持按账号查看本机缓存、按标题／ID 搜索。账号之间的数据隔离保存；断开登录后历史数据仍留在本机。同步失败保留已有数据和最近成功时间，并显示失败原因。

可开启“此页面可见时每 15 分钟同步”。该开关默认关闭，只在当前帖子数据页面保持打开且可见时运行；切换页面、账号或断开登录后停止，关闭浏览器后不会继续定时同步。运行中断的只读同步任务可在工作台重启后恢复。需要持续后台监测时可另行扩展。

## 仿写项目管理

采集笔记加入仿写库时，同一来源已有未删除项目就直接打开原项目，不重复创建，也不覆盖原文稿、素材或版本。已加入的笔记显示「查看仿写项目」，批量加入跳过已有项目。回收站项目不占用名额，可以重新加入；新建无来源创作不受此限制。已有的历史重复项目不会自动合并或删除。

仿写库的项目列表支持单个／批量删除，编辑器顶部也可删除当前项目。项目移入仿写库回收站，可单个／批量恢复；文案版本、素材选择、来源记录和已建立的发布稿保留。本机暂存的未保存文稿仍保留在原浏览器中。回收站项目需恢复后继续编辑；正在排队或执行文案生成的项目需等待任务结束后删除。该操作不清理素材文件或自动撤回发布稿。

仿写库回收站支持单个／批量「彻底删除」，确认后不可恢复，会删除项目、该项目的全部文案版本与生成任务记录，同时清理当前浏览器中的暂存文稿。已建立的发布稿是独立快照，仍保留且可继续查看和发布；其中的项目／版本 ID 作为历史来源标识。采集原文和本地素材不会连带删除，需要在各自模块管理。整批项目通过状态与任务检查后才执行删除，避免部分删除。

## 本地素材管理

点击右上角「本地素材」，或采集库「管理素材」、仿写库「管理本地素材」，即可预览已采集或上传的图片与视频。支持按名称搜索、类型／来源／分类筛选、分页、重命名和批量分类。分类可以输入新名称，留空表示未分类。

可一次选择或拖入多份自己的素材，并指定上传分类。文件复制到工作台本地媒体目录，上传完成后可在仿写素材选择器中选用。重命名更新显示名称和单文件下载名称，已有文稿及发布稿的素材引用保持有效；原始文件名保留供搜索。分类属于工作台标签，不会移动电脑上的原文件。

素材卡片的删除按钮、勾选后的「批量删除」会将素材移入素材回收站，默认素材库及新素材选择器不再显示，可单个或批量恢复。已有采集记录、仿写和发布稿仍可访问所引用文件。回收站支持单个／批量彻底删除，不可恢复；存在来源修订、仿写选择（包括非当前类型）、封面、发布稿或提取文本引用时会阻止整批操作并提示原因。正在处理的素材需等待任务完成。文件清理采用可重试后台任务，不删除上传前电脑上的原文件。采集来源引用的素材应通过采集库回收站清理对应笔记。

## 服务与边界

| 能力 | 默认模型／协议 |
|---|---|
| 仿写 | qwen-plus，兼容 Chat Completions |
| OCR | qwen3.5-ocr，图片 Base64 输入 |
| 原视频转写 | paraformer-realtime-v2，WebSocket 二进制 PCM 流 |
| 采集 | 固定提交的 XHS-Downloader 2.8，独立 Python 服务 |

无密钥时 AI 任务显示“待配置”，不会生成示例成功结果。配置后到“后台任务”重试。连接检测只验证所述连接／鉴权步骤，真实模型权限仍需实际调用确认。

图片支持 JPEG、PNG、WebP、GIF；视频支持 MP4、MOV、WebM，单个素材最大 512 MB。为保证浏览器播放，推荐 H.264/AAC MP4；MOV 或其他编码能否播放取决于浏览器，首版保留原文件，不自动转码。OCR 的 Base64 输入目前限制原图约 7 MB，过大时请上传压缩副本。原视频转写限制 30 分钟以内，无音轨会给出明确错误。

小红书访问结果取决于笔记链接、公开访问权限和平台状态；“采集服务连接正常”不表示任何笔记均可访问。下载域名采用允许列表，新的平台媒体域名需要审核后更新 `internal/adapter/http.go`。短链接由 Go 验证重定向并解析为完整笔记链接后交给采集服务。

原文、OCR 和转写在创建仿写项目时固定为来源快照。之后更正提取结果或重新采集不会改动旧项目；需要使用新来源时，从采集库重新建立仿写项目。所有历史提取结果继续保留。

采集表格每行提供“删除”，勾选多条后可“批量删除”。确认后笔记进入表格上方的“回收站”，可单条或批量恢复。删除不会改动已有仿写、发布稿、来源历史或本地素材，也不会释放媒体文件占用的磁盘空间。重复提交回收站里的链接会提示恢复，不创建重复记录。

回收站支持“彻底删除”和“批量彻底删除”，需再次确认，完成后不能恢复。笔记记录立即删除，未被引用的来源、提取结果及采集素材记录一并清理，文件通过持久化后台清理任务删除；被占用时可在“后台任务”重试。仿写来源、已选素材（包含暂未启用的图文／视频选择）、封面和发布稿引用的内容会保留，用户自行上传的文件不会被连带删除。相关素材正在处理或采集任务尚未结束时，需等待任务完成后再彻底删除。

## 数据与安全

```text
cmd/workbench/          Go 服务入口
internal/app/           API、业务流程、任务队列与外部调用
internal/domain/        数据模型
internal/store/         SQLite 访问及嵌入式数据库迁移
internal/adapter/       下载边界、协议辅助、Windows DPAPI
web/                    React / TypeScript / Vite / Ant Design
collector/              Python 采集包装服务、依赖锁、来源和许可证
publisher/              固定版本的扫码发布组件、补丁及许可证
scripts/                Windows 安装、检查、启动与停止
config/                 非敏感本地配置
data/db/                SQLite（WAL）
data/media/             已持久化媒体
data/exports/           旧版发布包（历史文件保留，不再生成）
data/tmp/               临时文件
data/publisher/         DPAPI 加密的扫码登录状态
logs/                   本地进程日志
.tools/                 项目独立工具与依赖缓存
```

只监听 `127.0.0.1`。Gin 校验 Host、Origin 和写请求的 CSRF 令牌；采集服务仅接受内部服务令牌，拒绝浏览器 Origin 请求。下载检查域名、每跳重定向、DNS 和实际拨号 IP；素材读取通过 Go `os.Root` 限制在媒体目录内。上传检查真实媒体类型，视频通过 FFprobe 检查。外部调用错误不原样回显请求体。

AI 密钥用当前 Windows 用户的 DPAPI 加密保存在 SQLite，查询接口只返回配置状态与掩码。上游 `params` 在 Python 和 Go 两层丢弃，不进入笔记快照和前端。服务令牌仅用于本机内部通信，不要将 `data` 目录加入版本控制或发给他人。

SQLite 保存任务队列：采集 1、媒体下载 1、OCR 2、转写 1、仿写 1、发布 1 并发。安全步骤在重启后恢复，运行中断的 AI 请求转为“待核实”，不自动重复付费调用。发布请求发出前保存待核实状态；中断或结果不明时不会自动重发，只有人工确认未发布才能重新提交。

## 备份与故障恢复

停止服务后复制整个 `data` 目录和 `config/local.json`，不要只复制正在运行的 SQLite 主文件。恢复时停止服务再覆盖对应备份。迁移到其他 Windows 账户／电脑后需要重新输入密钥。移入回收站不会释放磁盘空间；彻底删除后，通过后台任务清理未引用的文件。

常见问题：

- 页面打不开：运行依赖检查，查看 `logs/backend.err.log`，确认没有端口冲突。
- 采集服务未连接：查看 `logs/collector.err.log`，确认依赖安装完整。
- 网络连接失败：先检查网络。如果由受限开发工具启动，请双击 `restart.cmd`，在普通 Windows 环境中重新启动。
- 登录限制／链接异常：在浏览器确认笔记可以打开，再粘贴完整的最新分享链接。本工作台仅直接采集公开可访问的笔记，不提供登录凭证配置。
- 视频不能上传：检查 FFprobe，以及文件是否有有效视频流。
- 扫码服务未连接：双击 `restart.cmd` 加载新组件；检查 Chrome／Edge 和 `logs/publisher.err.log`。源码安装需重新运行 `setup.cmd`。
- 发布待核实：先在创作平台查看实际结果。已发布就记录作品链接；没有发布才点击“核实未发布，允许重新提交”。
- 服务重启：前端会重新取得 CSRF 会话；可在后台任务中查看恢复结果。
- 脚本路径：目录支持空格，但应保持项目完整移动，不能只移动可执行文件。

# 统一工作台说明

小红书和抖音共用同一个「内容工作台」，侧边栏统一保留采集库、仿写库和发布管理，不再切换平台工作区。采集库支持混合粘贴两种平台的链接并自动分流，列表默认展示全部平台，也可筛选。仿写项目与回收站统一展示，来源平台继续保留为标签。素材库、模型设置和后台任务继续共用。

在已确认的完整版本上点击「准备发布稿」后，可选择「只发小红书」「只发抖音」或「两个平台都发」。双平台一次建立两条标有「双平台同稿」的关联记录，详情中可切换查看两边的状态。发布管理统一展示两平台稿件，保留平台筛选，并同时提供两个账号的连接入口。分别核对实际账号和稿件后确认发布，建立稿件本身不会执行发布；一边成功、另一边失败时只处理失败的平台，结果不明时仍须先核实。两个快照引用同一份本地素材，不复制文件。窗口内重复点击和网络中断后的重试复用原创建请求，避免重复建立两份稿件。

旧的 `#xhs/collections`、`#douyin/rewrites` 等链接仍能打开对应模块，进入后展示统一列表。无需迁移、删除或复制已有项目、媒体和发布稿。前端构建更新后刷新页面即可看到合并界面。

素材选入只引用素材库中已有的文件，不复制文件、不创建新版本。同一素材重复选入会去重并保留已有顺序；视频和整组图片全部选入后按钮显示已选入。


### 创作流程更新（2026-10-13）

- 采集页手动粘贴链接后开始采集，不再提供读取剪贴板按钮。加入仿写库会直接打开新项目，不等待项目列表同步。
- 文案页只配置文案生成要求，篇幅可自由输入。图片模型在图片仿写页选择。
- 图片生成默认显示最近一次任务，历史生成折叠保留。结果可加入或取消加入当前草稿配图，不改变已保存版本；生成失败也不清除原图。
- 视频导演通过「从素材库选择」选择图片和视频参考（最多 7 份，其中视频最多 2 份）。参考视频用于抽帧和脚本分析，当前不会直接上传给视频生成模型。
- 「确认完整脚本」自动保存修改并确认。取消脚本后回到规划，取消状态由后端保存；该脚本无法再发起新生成。已提交任务仍可能继续执行并计费，已有媒体保留。
- 生成视频缓存后可预览，手动点击「下载到素材库」才加入素材库，并记录所属项目和脚本。远程生成成功但缓存失败时可重试查询和下载，不重新提交生成。完整连续视频可直接选入当前版本。
- 保存完整版本时可填写名称（最多 80 字）。完整版本对比包含标题、正文、话题、图片顺序、视频和封面；选用或确认版本不会直接发布。
- 更新后保存当前编辑并运行 restart.cmd，打开 http://127.0.0.1:8080。离线预览只是示例布局，不支持实际保存、采集或模型生成。

### 文案钩子

图片仿写的「本次参考图片」支持点击「从素材库选择」，搜索并预览已上传、采集或 AI 生成的本地图片，可多选、取消及移除。与原有来源图片使用同一份参考选择，编号按选择顺序排列；仅引用已有素材，不复制文件、不自动选入发布素材。选择上限按图片模型能力限制，连续画面预留首张成图的参考位；未启用参考图的图片模型需切换后才能带图生成。画面规划使用参考图片时，仍需支持图片理解的文案模型。

文案生成默认采用发帖作者的自然表达：直接给可发布的内容，保留用户提供的观点和用词，减少套话、整齐划一的模板、强行升华及互动口号。不会把来源博主的经历改成使用者的亲身经历，也不会用虚构生活细节、错别字或堆叠语气词模拟真人。用户指定的专业、正式等语气仍然有效。无需额外勾选或再次调用模型润色；规则随新生成任务和版本要求保存，旧文稿不自动重写。实际表达效果需用所选模型生成后检查。

「AI 建议角度」支持只填主题、只填文案或同时填写两者；会读取编辑器当前标题、正文和话题（含未保存修改），结合所选参考文字和补充要求，用本次文案模型生成 3 个备选话题。「发帖角度」可选，不要求同时填写主题和文案。可选用一个建议，也可跳过建议直接生成文案。没有模型密钥时仍可手动填写。

图片仿写增加「首图吸引方式」（自动、问题场景、细节特写、前后对比、结果展示、自定义）；视频仿写增加「开头吸引方式」（自动、动作开场、问题场景、提问开场、先展示结果、自定义）。两处角度留空时沿用文案角度，单独填写时只影响对应媒体。自定义钩子需填写具体要求；角度及自定义要求每项最多 1000 字。

图片仍先规划逐张描述，编辑后再生成图片；视频仍先规划完整脚本，确认后才制作。文案或对应角度、钩子变化时提示可重新规划，已有描述、脚本、图片和视频保留。继续制作旧脚本使用旧脚本内容。角度草稿在本机浏览器按项目暂存，点击「保存完整版本」后才作为版本保存在后端。

完整版本记录当时的创作主题、发帖角度和媒体钩子；完整发布稿对比可查看这些设置及所选 AI 素材生成时的实际画面、脚本、模型记录。当前版本角度与旧素材生成时角度可能不同，界面分别展示。旧版本不会被修改，旧资料缺少的字段显示未记录。新增字段保存在 SQLite JSON 数据中，兼容现有记录，无需重建数据库。

手动验收：填写主题并勾选参考帖子 → 可选建议并选用话题 → 生成文案 → 选择首图或视频开头钩子 → 规划、修改、确认 → 生成并选用素材 → 命名保存完整版本 → 修改角度另存版本 → 对比确认旧版及旧素材记录未变。真实模型调用由用户点击发起，可能计费。

仿写库 → 文案编辑 →「文案钩子」可选择自动选择、痛点共鸣、明确收益、提问悬念、反差切入、故事切入或自然直述。默认自动选择，并结合目标读者、语气、自由篇幅和补充要求生成。通用规则要求标题与正文一致、细节具体、事实可追溯，不虚构经历或效果；素材不足以支持故事或反差时自然直述。

每次生成保存所选钩子和完整生成要求，版本列表和完整版本对比中可查看。自动选择记录的是策略“自动选择”，不宣称模型实际选择了某个具体子类型。手动另存版本沿用来源版本的生成记录；旧版本没有记录时显示“未记录”，不会推测补填。该功能沿用所选文案模型，不增加额外模型调用。


## 仿写版本与草稿（2026-10-15）

- 新生成的 AI 文案进入「试写历史」，可选用、编辑和对比，不分配 V 编号。图片、视频继续保留各自生成结果；选入只是引用现有素材文件。
- 「保存完整版本」保存标题、正文、话题、素材顺序、封面和创作设置，允许自定义名称。同一项目内容相同则沿用已有版本，不重复增加编号；名称可通过「重命名版本」独立修改。旧版本编号保留，不将既有记录擅自改为试写。
- 完整版本仍可作为未配齐素材的草稿保存；「确认并选用完整版本」要求标题、正文、对应素材和本地文件齐全。图文、视频各记住一个当前选用版本，历史确认记录保留。建立发布稿仍需明确选择目标平台，不自动发布。
- 完整版本与试写记录可左右比较，并查看正文逐段变化、话题变化、素材新增/移除、顺序和封面变化。
- 编辑停止约 0.8 秒后自动保存到本机 SQLite，图文和视频草稿分别保存，包含文案、素材、创作设置、目标读者、语气、篇幅、要求和所选文案模型；界面显示保存时间或失败原因。浏览器缓存仍作应急备份。关闭前应看到「草稿已保存」；后台失败时不要清空本地缓存。
- 同时打开多个编辑页时，旧修订不能覆盖新修订，界面提示冲突。请先保留当前文字再刷新核对；重试不会强行覆盖其他页面的草稿。
- 数据字段以向后兼容方式加入现有 JSON 记录，无需重建数据库。已有发布稿的内容快照不受重命名、选用其他版本或后续编辑影响。

浏览器回归可在普通 PowerShell 中进入 web 目录执行 `npm run test:rewrite-ui`，需先 `npm run build`。该场景使用独立浏览器与模拟 API，不访问真实账号。当前开发环境启动 Edge 受限，实际交互验收仍需运行此场景或手动操作。

- 此次更新后新生成的图片、视频镜头、成片和自动封面默认只作为生成结果。为预览、连续画面参考和历史版本保留本地缓存，但不自动出现在素材库。
- 「下载到素材库」显式登记为素材库内容；重复点击复用同一条素材和同一文件。旧版已在素材库的内容继续保留。保存状态存入 SQLite，重启后保留。
- 「加入发布素材」与保存到素材库相互独立，加入后按钮变为「取消加入发布素材」。取消仅移除当前草稿引用，完整版本和既有发布稿不变。也可在「发布素材」页移除。
- 「选择封面」可以搜索素材库图片或选择本地 JPG/PNG/WebP（不超过 32 MB），先预览再确认。取消弹窗不上传本地文件；确认时上传并选作封面，可以再次替换或取消。选入视频不再自动绑定生成封面。
- 素材库参考选择器只展示已存入素材库的内容；生成结果仍可在生成页预览。生成封面可以单独保存到素材库后再选择。
- 本地封面选择不代表各平台自动上传都支持该封面；当前小红书扫码上传仍使用平台默认封面，按官方编辑页实际能力处理。
- 手动验收：生成图片/视频 → 素材库中尚未出现 → 加入再取消发布素材 → 保存到素材库 → 重复保存无重复 → 选择本地封面预览后取消（不上传） → 从素材库预览并确定 → 保存完整版本后取消当前素材，确认旧版预览仍完整。
- 模拟界面测试：`npm --prefix web run test:media-ui`（需要本机 Edge 可启动）。不调用真实生成或发布服务。

图片生成结果已移除单张和整组的「替换当前图片」按钮；使用「加入发布素材」「取消加入发布素材」逐张调整，连续画面仍支持追加整组。

### 小红书扫码连接（2026-10-16）

更新后双击 restart.cmd，刷新页面后点击「扫码连接」。此时会打开专用小红书浏览器，请保持它打开；用手机扫码并确认。如官方要求验证，在该专用窗口本人完成。工作台会显示等待扫码、验证中、需要验证、过期或失败；核实账号并保存成功后显示已登录。不要连续点击重新获取；二维码过期再重新获取。此次更新不清除已有密钥或登录文件，也不会提交作品。


### 简化发布操作与视频结果

小红书发布稿列表提供“上传到小红书、复制文案、记录已发布、查看发布稿”。已准备的稿件再次点击上传会打开原官方窗口；需要重新准备时，从稿件详情核实未发布后操作。小红书与抖音的手动发布记录只需确认发布时间，不必填写作品链接，已有作品链接和标识保留。

视频仿写直接使用模型生成的视频，可预览、选择保存到素材库或加入/取消发布素材，不再提供“预览满意，制作成片/合成成片”入口。以前生成的成片仍可查看与使用；后台保留旧合成任务的兼容处理。


### AI 创作角度

“AI 建议角度”根据主题或当前文案（两者都有时结合分析），并结合选中的参考帖子和用户补充要求，提出三个让读者感兴趣的话题方向。话题自然表达，不要求“读者、处境、价值”等固定结构，也不要求模型输出 JSON。程序可识别常见段落、编号和列表；无法可靠拆分时保留原文供手动选择，不因排版报格式错误，也不为整理格式额外调用模型。建议只有经用户选用后才进入创作角度，不自动生成或替换文稿。


### 干净分发包

`scripts/package-release.py` 从源码与编译产物重新构建 Windows 便携分发包，命名必须是新的输出目录；不会从个人数据目录复制内容。运行依赖内置，源码仅保存一份 ZIP。使用 `--name` 指定版本目录，`--node` 指定附带 LICENSE 的 Node.js 可执行文件。先完成前后端编译；打包后用 `check.cmd` 检查依赖。运行版不需要 Go 或 npm。原工作台与分发版不能同时占用默认端口。


### 分发版模型预设

`config/model-presets.json` 仅包含配置名称、API 地址、模型 ID 和参考能力参数，不包含密钥或会话。分发版通过 `config/local.json` 的 `model_presets` 指定它；首次启动在事务中导入到新数据库，已有配置和密钥不覆盖，之后重启不会恢复用户删掉的预设。预设导入后均显示待配置，接收方只需在相应模型配置中填写自己的密钥；OCR/转写在设置中填写。百炼使用当前专用工作空间地址，接收方密钥须具有该地址的权限，独立工作空间需修改 API 地址。模型权限与可用性由服务商决定。
